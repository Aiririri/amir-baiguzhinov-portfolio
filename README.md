# Amir Baiguzhinov — Personal Portfolio

A minimalist, responsive personal portfolio website created as the personal website component of the Software Engineering TSIS project.

**Live project:** [Repository](https://github.com/Aiririri/amir-baiguzhinov-portfolio)  
**Personal GitHub:** [@Aiririri](https://github.com/Aiririri)  
**Featured project:** [Aruskin.ai](https://aruskin.com/)

## About

The website introduces Amir Baiguzhinov, a Software Engineering student at Kazakhstan-British Technical University (KBTU) and Founder & CEO of Aruskin.ai. It presents education, experience, projects, areas of interest, and languages.

## Website sections

- Home
- About and languages
- Education
- Experience
- Selected project: Aruskin.ai
- Skills and areas of focus
- Personal interests
- Contact links

## Technology

- HTML5
- CSS3 (responsive layout, custom properties, media queries)
- Vanilla JavaScript
- Google Fonts (DM Sans, Manrope, DM Mono)

No build step or package installation is required.

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern browser.

For a local HTTP server, you can use the Live Server extension in Visual Studio Code or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The TSIS brief specifies deployment to InfinityFree with a free subdomain and HTTPS. Deployment is a separate step and must be completed and tested before the final submission. Upload the website files to the hosting account's web root (commonly `htdocs`) and verify the public HTTPS URL.

## Project status

The initial website implementation is committed to the `main` branch. Browser testing, manual user testing, hosting deployment, and final TSIS evidence/report preparation must be completed and documented separately. Do not treat these steps as complete until they have actually been performed.

## Accuracy note

Portfolio content is based on information supplied by the site owner. No personal email address, phone number, awards, employment dates, or unverified achievements are published. The KBTU programme label is kept as supplied (`ВТиПО`); confirm the official English programme name before changing it.
